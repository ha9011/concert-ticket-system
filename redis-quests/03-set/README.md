# 03. Set — 중복 없는 멤버 집합

> Redis Set: **순서 없는, 중복 없는 값들의 모음.** "있다/없다"와 "집합 연산(교집합·합집합·차집합)"이 핵심.
> 한 문장: **"멤버십(membership) 검사와 집합 연산이 O(1)~빠른 자료구조."**

## 이 프로젝트와의 연결

콘서트 티켓 시스템에 Set을 이식하면:

- **찜한 아티스트**: `favorite:user:{id}` → 사용자가 찜한 아티스트 집합. 중복 자동 제거.
- **공통 관심사**: `SINTER favorite:user:1 favorite:user:2` → 두 사용자가 함께 찜한 아티스트.
- **중복 방지**: `SADD`의 반환값(1=신규, 0=이미 있음)으로 "이미 찜했나?" 판단.
- **콘서트 태그**: `tags:concert:{id}` → 공연에 붙은 장르/키워드 집합.
- **알림 수신 대상**: 아티스트를 찜한 사용자 집합 → 새 공연 등록 시 Fan-out 대상(List 챕터와 연결).
